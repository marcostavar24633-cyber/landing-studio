# Universal Design System — Studio

Единая библиотека визуальных принципов и интерфейсных решений для проектов владельца аккаунта. Система состоит из общего ядра и независимых профилей брендов. Общие компоненты не должны стирать индивидуальность каждого бренда.

## Принципы
- Mobile-first, адаптивность от 320 px.
- Доступность: семантическая разметка, видимый focus, контраст, клавиатурная навигация, reduced motion.
- Производительность: лёгкие эффекты, оптимизация изображений, отсутствие тяжёлых библиотек без необходимости.
- Конверсия: ясная иерархия, один главный CTA на экран, понятные состояния форм.
- Повторное использование: токены и компоненты ядра; цвета, шрифты и радиусы — через профиль проекта.
- Не переносить фирменные цвета/логотипы/тексты одного бренда в другой без отдельного решения.

## Структура
- `tokens.css` — базовые дизайн-токены и семантические роли.
- `components.css` — базовые паттерны кнопок, карточек, полей, контейнеров.
- `projects.md` — профили проектов и их отличия.
- `motion.md` — правила анимации и параллакса.
- `implementation.md` — подключение к React/Vite и обычным HTML-проектам.

## Проекты в текущем реестре
Слопай букет, ПЕНКА, РАКОВАРНЯ 73, Photograf, ДомА Тех, Hair, Landing Studio. Реестр основан на доступных GitHub-репозиториях и истории работы; перед извлечением точных значений цветов/шрифтов каждого проекта их CSS следует сверить отдельно.

## Правило внедрения
Сначала подключать только ядро. Затем выбирать профиль бренда и задавать его токены. Не заменять существующий дизайн проекта глобально без отдельного согласования.
