# Landing Studio

Конструктор адаптивных лендингов с настройками.

## Быстрый старт

1. Скачайте архив проекта `landing-studio-my-business.zip`.
2. Распакуйте архив.
3. Откройте файл `landing-studio-my-business/index.html` в браузере.
4. Нажмите «Настроить сайт», чтобы изменить тексты, разделы, палитру и карточки.

## Возможности

- Адаптивная страница для компьютера и телефона.
- Тёмная и светлая цветовые палитры.
- Редактирование заголовков, описаний, услуг и FAQ.
- Сохранение настроек в браузере.
- Экспорт готовой HTML-страницы.
- Печать и сохранение в PDF.

## Важно

Форма заявки в демонстрационном проекте пока не отправляет данные на сервер. Для приёма реальных заявок нужно подключить обработчик или ссылку на мессенджер/e-mail. Перед публикацией замените демонстрационные тексты и добавьте только подтверждённые контакты, цены и отзывы.

Настройки редактора сохраняются локально в браузере и не синхронизируются между устройствами.
