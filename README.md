# Landing Studio

Универсальный конструктор адаптивных лендингов с библиотекой блоков.

## Демо
https://marcostavar24633-cyber.github.io/landing-studio/

## Как пользоваться
1. Откройте демо и нажмите «Настроить сайт».
2. Создайте проект или копию в «Мои проекты».
3. В «Структура страницы» перетаскивайте блоки, используйте ↑/↓, скрывайте, добавляйте, копируйте и удаляйте дополнительные блоки.
4. Настройте тексты, цвета, шрифт, ширину контента, фотографию и SEO-поля.
5. Проверьте режимы «Десктоп / Планшет / Мобильный», запустите проверку страницы и скачайте HTML.

## Библиотека блоков
Основные: первый экран, о компании, услуги, преимущества, этапы, отзывы, галерея, стоимость, FAQ, контакты и форма.
Дополнительные: каталог, сравнение тарифов, команда, сертификаты, партнёры, доставка и оплата, блог, квиз-заготовка, карта, видео, скачивание материала, акция. Дополнительные блоки — редактируемый текстовый каркас; сложные интерактивные сценарии требуют отдельной разработки.

## Сохранение и перенос
Несколько проектов сохраняются локально в браузере. Используйте экспорт/импорт JSON для резервной копии и переноса. Очистка данных сайта в браузере может удалить локальные проекты.

## Ограничения
- Нет серверной базы, аккаунтов, облачной синхронизации и общей панели заявок.
- Форма открывает почтовое приложение или мессенджер при наличии контакта. Хранение заявок, уведомления, CRM и антиспам требуют отдельного backend или сервиса форм.
- Домен и SSL настраиваются отдельно в хостинге.
- Проверка перед публикацией вспомогательная; контакты, ссылки, цены, юридические тексты и согласия нужно проверить вручную.
- Не публикуйте персональные данные клиентов и неподтверждённые отзывы/сертификаты.


## AI-агент «Создать сайт с AI»

В интерфейсе добавлена кнопка **«Создать сайт с AI»**. Пользователь вводит только нишу. Агент самостоятельно формирует маркетинговый бриф, аудиторию, оффер, тексты, услуги, преимущества, этапы, FAQ и визуальное направление. Для исследования публичных рыночных предложений backend включает веб-поиск и показывает использованные источники; стиль и палитра влияют на оформление страницы. После просмотра результата можно создать новый проект в редакторе.

### Подключение AI и публикация на Vercel

AI-агент использует OpenAI Responses API и встроенный веб-поиск. Серверная функция находится в `api/generate-landing.js`; ключ API не передаётся в браузер.

1. Создайте API-ключ в [OpenAI API Platform](https://platform.openai.com/api-keys). Подписка ChatGPT и оплата API — разные продукты; для API должен быть настроен биллинг в API Platform.
2. Откройте [Vercel](https://vercel.com/) и импортируйте GitHub-репозиторий `marcostavar24633-cyber/landing-studio` (или загрузите этот ZIP в новый репозиторий).
3. Для проекта выберите Framework Preset `Other`, Build Command оставьте пустой, Output Directory — `.`.
4. В Settings → Environment Variables добавьте `OPENAI_API_KEY` со значением своего ключа. Не добавляйте ключ в `.env.example`, HTML, JS браузера или GitHub.
5. Добавьте `OPENAI_MODEL` со значением `gpt-6-astra` (можно оставить значение по умолчанию). Запросы используют Responses API, встроенный веб-поиск и Structured Outputs; ответы не сохраняются через параметр `store: false`.
6. Нажмите Deploy. После публикации откройте адрес сайта и проверьте `/api/generate-landing`: должен вернуться JSON со `status: "ok"` и `configured: true`.
7. Вернитесь на главную, нажмите «Создать сайт с AI», введите нишу и запустите генерацию.

`index.html` загружает интерфейс из `app-chunks/` и `landing-studio-app.html.gz`; эти файлы должны находиться в корне публикации рядом с `api/` и `vercel.json`. На GitHub Pages серверная функция не запускается — для AI нужен Vercel или другой Node.js serverless-хостинг.

### Важные ограничения

- Результат AI — рабочий черновик, а не подтверждённое исследование рынка. Перед публикацией проверьте гипотезы, факты и тексты.
- Агент не выдумывает цены, отзывы, сертификаты, контакты и гарантии. Неизвестные сведения перечисляет как требующие подтверждения.
- API-запросы оплачиваются отдельно в OpenAI API Platform. Перед открытым публичным запуском добавьте ограничение частоты запросов (например, Redis/Upstash) и CAPTCHA/Turnstile: встроенная серверная функция пока не реализует общую межинстансовую защиту от злоупотреблений.
- Ключ хранится только в переменных окружения серверного хостинга.
