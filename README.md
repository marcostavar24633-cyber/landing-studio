# Landing Studio

Конструктор адаптивных лендингов, который можно открыть в браузере на компьютере или телефоне.

## Демо
https://marcostavar24633-cyber.github.io/landing-studio/

## Быстрый старт
1. Откройте демо-сайт и нажмите «Настроить сайт».
2. В блоке «Мои проекты» создайте новый проект или скопируйте существующий.
3. Измените тексты, услуги, палитру и контакты.
4. При желании загрузите фотографию первого экрана (до 2 МБ).
5. Сохраните настройки и скачайте готовый сайт в HTML.

## Возможности
- Адаптивная вёрстка для телефона и компьютера.
- Тёмная и светлая темы, цвет акцента.
- Несколько проектов: создание, копирование, переключение и удаление.
- Экспорт и импорт проектов в JSON.
- Загрузка фотографии первого экрана.
- Экспорт отдельной HTML-страницы и печать в PDF.

## Хранение данных
Проекты сохраняются только в браузере на текущем устройстве. Они не синхронизируются с GitHub или другими устройствами. Для переноса используйте экспорт и импорт JSON. Очистка данных сайта в браузере может удалить проекты — храните резервные JSON-файлы.

## Ограничения и безопасность
- Серверной базы данных и учётных записей нет.
- Форма заявки не отправляет данные на сервер: она открывает почтовое приложение или указанный мессенджер.
- Не добавляйте персональные данные клиентов, пароли и другую конфиденциальную информацию.
- Перед публикацией замените демонстрационные тексты, цены, контакты и отзывы на подтверждённые сведения.
- Фотография первого экрана сохраняется в браузере и включается в экспортируемый HTML.

## Файлы
- `index.html` — приложение, публикуемое через GitHub Pages.
- `landing-studio-app.html.gz` — сжатая копия приложения, загружаемая стартовой страницей.
- `landing-studio-my-business.zip` — архив проекта.
