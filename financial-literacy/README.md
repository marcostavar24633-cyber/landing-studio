3. Подтвердить название организатора, сведения об экспертах, формат и расписание занятий.
4. Уточнить стоимость, длительность и условия программ.
5. Добавить политику обработки персональных данных только если позже появятся формы/аналитика, собирающие персональные данные.
6. Проверить правовые требования к рекламе образовательных и финансовых услуг в зависимости от фактической модели бизнеса.
